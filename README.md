## Base 11ty site

Minimal Eleventy starter with:

- `src/` input + `_site/` output
- Nunjucks templates (`.njk`)
- Data-driven navigation via `src/_data/site.config.json` + `src/_data/site.js`
- Tailwind CSS via CLI

### Install

```bash
npm install
```

### Dev

Runs Tailwind watch + 11ty dev server:

```bash
npm run dev
```

### Build

```bash
npm run build
```
